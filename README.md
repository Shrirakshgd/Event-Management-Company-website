# Ashirwad Weddings & Events

> An ultra-luxury event management website curating bespoke destination weddings, stadium-scale live concerts, and exclusive private celebrations for HNIs, NRIs, and commercial organizers.

![Website Preview](https://images.unsplash.com/photo-1519741497674-611481863552?auto=format&fit=crop&w=1200&q=80)

---

## 🌟 Key Features

- **Luxury Aesthetics**: Gold-accented, elegant dark theme tailored for high-end hospitality and event production.
- **Interactive Portfolio Gallery**: Filterable showcase (Weddings, Concerts, Corporate, Galas) with category switches.
- **Fullscreen Lightbox**: Interactive modal displaying high-res photos, guest capacity, venue specs, and direct inquiry link.
- **Testimonial Slider**: Smooth testimonial carousel featuring client reviews and ratings.
- **Accordion FAQ**: Expandable questions and answers covering venues, logistics, budget guidelines, and booking timelines.
- **Consultation Inquiry Form**: Multi-field consultation booking form with validation.
- **Fully Responsive**: Mobile-first architecture with custom navigation drawer and touch-friendly controls.
- **Zero Heavy Dependencies**: Pure Vanilla HTML5, CSS3, and JavaScript — blazingly fast load times and clean code.

## 🚀 How to Run Locally

You can run this project locally using any of the following simple methods:

### Method 1: Using Python (Recommended — No setup required)

If you have Python installed:

1. Open your terminal / PowerShell in the project directory:
   ```bash
   cd "event management company"
   ```

2. Start the local HTTP server:
   ```bash
   python -m http.server 8000
   ```

3. Open your browser and visit:
   ```text
   http://localhost:8000
   ```

---

### Method 2: Using Node.js / `npx`

If you have Node.js installed, run either of these commands without installing anything globally:

- **Using `serve`**:
  ```bash
  npx -y serve .
  ```
  Then visit `http://localhost:3000`.

- **Using `live-server` (Auto-reloads on file save)**:
  ```bash
  npx -y live-server
  ```
  This will automatically launch the website in your default browser.

---

### Method 3: Using VS Code Live Server Extension

1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension by *Ritwick Dey* (from the Extensions tab `Ctrl + Shift + X`).
3. Right-click on `index.html` and click **"Open with Live Server"**.

---

### Method 4: Directly in Browser

Simply double-click the `index.html` file or drag-and-drop it into any web browser (Chrome, Edge, Firefox, Safari).

## 🌐 Deploy to GitHub Pages (Free Hosting)

To make this website live on the internet for free using GitHub:

1. Push your repository to GitHub.
2. In your GitHub repository, go to **Settings** > **Pages** (on the left sidebar).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Within 1-2 minutes, your website will be live at:
   `https://<your-username>.github.io/<repository-name>/`
